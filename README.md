# Covery Shoes

**Covery Shoes** is a simple, responsive HTML website designed to showcase and sell shoes online.

## Features
- Mobile-friendly layout
- Easy-to-edit product cards
- Social media links to Facebook and Instagram

## How to Use

### 1. Open and Edit
- Open `index.html` in any text editor (e.g., Notepad++, VS Code).
- To add or change shoes:
  - Copy any `<div class="product">...</div>` block
  - Replace the image filename, name, and price

Example:
```html
<div class="product">
  <img src="your-shoe.jpg" alt="Your Shoe Name">
  <h3>Your Shoe Name</h3>
  <p>€Your Price</p>
</div>
